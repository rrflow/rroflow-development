Decide what deserves attention

A signal is a rule that points you to a moment worth reviewing. A match is a clue, not a verdict.

Advanced: where rules run

Built-in rules run in the collector before text is removed. Custom rules run here when a turn arrives, using only uploaded, scrubbed information. Phrase rules cannot inspect text that stayed on your computer.

Saving a rule does not backfill history. A re-sent turn is evaluated with the current custom rules. Pausing keeps earlier findings and saved decisions until a turn is re-sent. Saved definitions remain available for interpreting evidence; create a new signal to change a rule.

Before anything is used for learning

  1. Choose which projects and sources may be used, and for what purpose.
  2. Preview included and excluded examples, with privacy checks.
  3. Build a fixed dataset version with source references and separate evaluation examples.
  4. Test an improvement, compare evidence, and keep a way to undo it.

Dataset permission, training permission and activation are separate choices. These controls are still being built.
