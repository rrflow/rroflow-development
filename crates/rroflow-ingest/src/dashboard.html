    Decide what deserves attention

    A signal is a rule that points you to a moment worth reviewing. A match is a clue, not a verdict.

    Advanced: where rules run

    Built-in rules run in the collector before text is removed. Custom rules run here when a turn arrives, using only uploaded, scrubbed information. Phrase rules cannot inspect text that stayed on your computer.

    Saving a rule does not backfill history. A re-sent turn is evaluated with the current custom rules. Pausing keeps earlier findings and saved decisions until a turn is re-sent. Saved definitions remain available for interpreting evidence; create a new signal to change a rule.

    Installation steps & current availability

    Claude Code & Codex

    The development branch reads this user's linked Claude Code and Codex session folders across projects, saves a local queue and retries delivery. Hosted connection setup is still being completed.

    rroflow login
rroflow whoami
rroflow sources link
rroflow sources service install

    These are development-branch commands. The published v0.3.0 collector predates this source workflow. Verify your collector supports sources service --help before using them. Installation enables startup for your current user. Windows requires that user to remain logged in; Linux logout persistence requires an explicitly configured user manager. Use sources service stop to pause capture, or sources service remove to remove startup while keeping captured data. Check Sources for delivery reports.

    Text stays local unless content capture is enabled. Configure the intended server before signing in; this dashboard does not provision a cloud connection.

    SDK applications

    JavaScript adapters exist for Claude, Codex and Grok, verified with fixture providers. They journal SDK events locally and retry delivery. They do not capture unrelated apps or subscription browser history.

    Read installation and linking notes ↗

    An SDK adapter sees calls made through that adapter. It cannot read your subscription app history. Explicitly linked SDK queues can retry through the updated managed collector after the app exits.

    Keep SDK delivery running

    For a computer with an existing linked collector, link the private queue and install the current collector build:

    rroflow sources sdk link --spool /absolute/private/sdk-queue
rroflow sources service install

    For SDK-only use, first run rroflow sources link --sdk-only. Configure the SDK with that queue and the same verified account and endpoint. These commands require the updated development build; an older pinned service needs an upgrade. Check Sources for queued events and retry problems.
