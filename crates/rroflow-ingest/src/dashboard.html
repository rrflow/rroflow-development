The development branch supports machine-wide session discovery, a durable local queue and retry. Startup installation and hosted connection setup are still being completed.

These are development-branch commands. The published v0.3.0 collector predates this source workflow. Verify your collector supports sources --help before using them. Keep the collector running; automatic startup is not installed.
