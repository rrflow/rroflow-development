Your agents

Send activity from this computer

Install the rroflow collector, then sign in with the same Shippin account used here. Run these commands on the computer where you use your agents:

rroflow login
rroflow whoami
rroflow ingest-claude <Claude sessions folder>
rroflow ingest-codex <Codex sessions folder>

Default folders: ~/.claude/projects and ~/.codex/sessions (on Windows, $HOME/.claude/projects and $HOME/.codex/sessions). Pass the actual folder path. Refresh this page after capture.

These commands send metrics and signal results; prompt, response and tool text stay local unless you add --content. Existing Claude and Codex sign-ins stay in their own apps. If you previously sent with an ingest key, that devspace needs to be claimed for your verified Shippin account.
