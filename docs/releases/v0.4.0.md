## What this release establishes

The released application includes account-scoped monitoring, session and SDK evidence, managed collector recovery, configurable account allowances and explicitly consented metadata datasets. It remains a development release. JavaScript SDK wrappers are in the repository source and are not yet published to npm.

This record does not establish Texas placement, production backup/restore, public member sign-in, subscription synchronization, training or production scale. Configure a verified deployment before linking an account. Dataset collection requires member consent and a configured worker; saving reviews does not start training. Existing user preview processes were preserved.
